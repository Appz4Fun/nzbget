Numbered options, such as the settings of each news server, are listed once with `N` in place of the number: `ServerN.Host` stands for `Server1.Host`, `Server2.Host`, and so on. Set any option for one run with `-o Name=value` on the command line.

> The descriptions below come straight from `nzbget.conf`, much of it written for NZBGet, so their style differs from the rest of this site.
